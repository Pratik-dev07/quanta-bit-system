# Quanta Bit System — 3D Premium Studio

A full React + Three.js + Express/MongoDB startup website inspired by the latest approved visual concept: dark cinematic surfaces, electric orange, futuristic 3D objects, mountain/architectural silhouettes, and strategic motion — without using portraits or historical images.

## Run

```powershell
cd "C:\My web\quanta-bit-system"
npm run install:all
npm run dev
```
Open http://localhost:5173

MongoDB is optional for the homepage. Copy `server/.env.example` to `server/.env` if you want contact enquiries saved to MongoDB.
